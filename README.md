# Yandex Tone of Voice — AI-копирайтинг для лендингов «как Яндекс»

Открытый `SKILL.md` для Codex, Claude Code и других AI-агентов. Помогает написать
русскоязычный лендинг или продуктовую страницу в стиле Яндекса, адаптировать
готовый текст либо провести Tone of Voice-аудит.

Это независимая редакторская реконструкция по открытым материалам, не официальный
брендбук и не проект Яндекса. Карта источников хранит основания и ограничения;
сходство со стилем не подтверждает факты, партнёрство или готовность к публикации.

## Что попросить

| Задача | Запрос | Результат |
| --- | --- | --- |
| Создать | «Напиши первый экран как Яндекс» | Текст в запрошенном формате, без выдуманных возможностей |
| Адаптировать | «Перепиши в стиле Яндекса, сохрани условия» | Новая версия без усиления обещаний и потери существенного смысла |
| Аудировать | «Проверь голос, только замечания» | Вердикт и цепочки `фрагмент → правило → последствие → направление` |

Можно работать с целой страницей или отдельным блоком, кнопкой, FAQ. Аудит не
означает автоматическое переписывание. Смешанный запрос сохраняет ваш порядок
результатов; без указанного порядка аудит предшествует новой версии.
Навык не запускается только из-за слова «Яндекс»: настройка Директа, API-клиент,
перевод статьи и обычная корректура без смены голоса — другие задачи.

## Быстрый старт

Установите через [skills CLI](https://github.com/vercel-labs/skills):

```bash
npx skills add Dankosik/yandex-tone-of-voice-skill -g
```

Или используйте ручную установку в каталог навыков вашего хоста. Пример
для Codex:

```bash
git clone https://github.com/Dankosik/yandex-tone-of-voice-skill ~/.codex/skills/yandex-tone-of-voice
```

Совместимость этих способов со всеми версиями хостов отдельно не проверялась. Передавайте факты и ограничения вместе с задачей, например:

```text
Используй yandex-tone-of-voice.
Создай первый экран сервиса сверки договоров для малого бизнеса.
Факты: выделяет условия и возможные риски; окончательное решение принимает юрист.
CTA — «Посмотреть возможности». Только текст, без редакторских примечаний.
Не придумывай тариф, сертификаты и гарантию юридического результата.
```

Уже известные данные не нужно повторно согласовывать. Если запрошенное обещание
невозможно обосновать имеющимися фактами, навык уточнит решающий пробел.
Структуру, число вариантов, лимит длины и фрагменты «без изменений» задавайте явно.

## Что сохраняется при работе со стилем

Продукт помогает человеку решить конкретную задачу. Массовый текст проще и теплее,
B2B — предметнее, Developer/Cloud — технически точнее. Формулы и словарь служат
выбору, а не требуют вставлять «помощник» или «сам» в каждый блок.

Адаптация сохраняет числа, факты, URL, степень уверенности и условия, но не обязана
сохранять неподтверждённую похвалу. Плейсхолдеры, названия и защищённые цитаты не
нормализуются. Для чувствительных обещаний применяется соответствующий раздел,
а не полный финансовый или правовой аудит. Подготовка текста не означает разрешение
опубликовать его или изменить файлы сайта.

## Проверки при сопровождении

```bash
python3 -m unittest discover -s tests -v
```

Тесты на стандартной библиотеке Python проверяют ресурсы, ссылки, структуру
сценариев и разделение входов и ожиданий. Они не оценивают качество русского текста,
поведение моделей, конверсию или юридическую корректность. Модельные сравнения
новой редакции **не выполнены**; протокол находится в `evals/README.md`.
