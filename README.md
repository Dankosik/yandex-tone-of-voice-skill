# Yandex Tone of Voice Skill

Независимая реконструкция Tone of Voice русскоязычных продуктов Яндекса для AI-агентов, использующих формат `SKILL.md`.

Навык создаёт и адаптирует продуктовые тексты, а также проводит read-only аудит. В основе — исследование открытых официальных страниц Яндекса; это не официальный брендбук и не проект Яндекса.

## Установка

```bash
git clone https://github.com/Dankosik/yandex-tone-of-voice-skill ~/.codex/skills/yandex-tone-of-voice
```

## Использование

Попросите агента написать текст «как Яндекс», адаптировать исходник в этом голосе или проверить соответствие ему. Навык сам выбирает одну из трёх ветвей: создание, адаптация или аудит.

## Состав

- `SKILL.md` — процесс и критерии завершения;
- `references/tone-system.md` — голос, регистры, лексика и приёмка;
- `references/source-map.md` — официальные источники и границы исследования;
- `evals/evals.json` — проверочные сценарии для трёх ветвей.
